# Support

- For setup and development guidance, start with the
  [development guide](docs/engineering/development.md) and the
  [README](README.md).
- For a reproducible problem, use the
  [bug report form](https://github.com/alvarolorentedev/opencode-mobile/issues/new/choose).
- To suggest an improvement, use the same issue chooser and select **Feature request**.
- For security vulnerabilities, follow the private process in [SECURITY.md](SECURITY.md).
- For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- For ways to support the project, visit the existing
  [support page](https://getopencode.app/support/).

Do not post passwords, access tokens, private server URLs, or personal
information in public issues or pull requests.
