# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, pull
requests, or discussions. Use [GitHub's private vulnerability reporting form](https://github.com/alvarolorentedev/opencode-mobile/security/advisories/new).

When possible, include the affected app version, platform, server version, and
steps needed to reproduce the issue. Do not include credentials, access tokens,
or private user data in a report.

Please keep the report private while it is being reviewed. This policy does not
promise a response time or a support window for specific app versions.
